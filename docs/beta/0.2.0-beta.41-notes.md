# Agent Time 0.2.0-beta.41

Review matching visits together. Each app now opens into compact groups for the same page, window or project; activity without extra context appears as General activity. Select a group to assign all its eligible visits in one action.

Your Mac activity is clearly identified as estimated human activity. The review summary, filters and sidebar badge count groups instead of hundreds of individual visits. Different projects and review decisions stay separate.

View visits opens the original periods when you need details, notes or split editing. Visit lists load in batches, timestamps include seconds, and the timeline reveals the selected visit even when it was hidden. Undo, existing split protection, timing calculations and stored history remain unchanged.
