# Agent Time 0.2.0-beta.56

Review activity with Unified, By category and Chronological views. Timeline and row selections stay synchronized. Configure grouping by project, device, browser, page URL/title and short activity duration. Assign an entire row and its descendants through the project menu or drag it onto a project, including project groups and Unassigned.

Home, Review and Reports share the selected project and day, week, month or custom period. The date selector now replaces breadcrumbs in the top toolbar; custom ranges open in a popover. Search and detailed filters remain with each page, alongside retained layout, selection and scroll context. Home, Review and evidence use an explicitly selected day within the period; Time and new Billing reports use the whole period. Token totals follow the selected period; live account limits remain account-wide.

Billing reports explain measured time, activity counting, commercial rounding and coverage separately. Saved reports and exports retain their original scope and totals. Range reports yield between daily calculations so capture can continue between days.

Capture history, timing/counting rules, billing policy calculations and existing saved report totals are unchanged. No productivity score is introduced. This release changes presentation, filtering and report scope; it does not rewrite recorded observations or automatically assign additional time.
