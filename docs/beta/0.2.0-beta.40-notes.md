# Agent Time 0.2.0-beta.40

Review your day by app: a timeline shows recorded app activity and project assignments, followed by expandable app sections with time totals and individual visits.

Select an app or several visits, then assign or reassign them together from one shared bar. Undo, leave unassigned, notes, split editing and future website rules remain available. Keyboard shortcuts support fast review while project pickers and buttons keep their normal keyboard behavior.

Recorded timing and history are unchanged. Gaps remain separate, and large app sections load visits in batches. The Home timeline loading indicator stays compact.
