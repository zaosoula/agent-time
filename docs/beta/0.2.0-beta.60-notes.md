# Agent Time 0.2.0-beta.60

You can now correct recorded agent time. In the Session explorer, each recorded interval of an agent execution can be shortened or removed, for example a night an agent spent waiting on scheduled checks. Corrections apply to one day at a time, can be undone, and leave captured evidence untouched. Corrected time is removed from every total: day, Home, timeline, projects, weekly review, CSV, billing, MCP tools, menu bar and widget.

Reviewing a past day no longer shows a looping "Unsupported operation or parameters" error.

Usage costs cover 25 more OpenAI and Claude models from the official price pages, with existing rates unchanged. Agent Time also starts normally when the Mac's clock is behind the date of its price list.
