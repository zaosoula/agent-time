# Closed beta limits

- Time is an evidence-based estimate. Agent and human intervals are separate; overlapping work is not additive. Do not use beta totals for billing or payroll.
- No event is inferred for an agent session before hooks were installed or trusted. A configured hook is not proof of delivery. Codex trust approval and provider hook changes can require repair.
- Orca supplies orchestration context. If it is unavailable, project attribution and run/task grouping may be incomplete. Remote-host capture is not yet validated.
- Accessibility is optional. Without it, Orca selected-tab and browser URL evidence may be unavailable. Browser tracking is per browser and can store full local page URLs and titles when enabled.
- Usage numbers depend on local logs, source availability, and pricing catalog coverage. Unpriced tokens remain visible separately.
- The first beta supports Apple Silicon only. The build floor is provisionally macOS 13.5 because of bundled Node; the actual supported minimum is pending clean-machine verification. A multi-day resource and database soak is also pending.
- No automatic history upload or cloud backup exists. In-app updates are a beta release gate and require real signed upgrade testing before invitations.
