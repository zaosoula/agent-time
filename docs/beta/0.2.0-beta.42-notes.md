# Agent Time 0.2.0-beta.42

Reconciliation now opens on Needs a project, showing only activity without a project or with conflicting matches. Automatically and manually assigned time is available under Assigned or All activity. Activity you deliberately left unassigned stays under All activity.

Automatic matches already count toward their projects and need no confirmation. Labels now say Automatically assigned, and visit details explicitly say Already counted. Change project is available for corrections; the individual action stays disabled until you choose a different project. Mark day reviewed no longer implies that project matches need approval.

Assigning an unresolved group removes it from the pending list; Undo restores it. Existing saved review preferences migrate to the new default once. Future website rules can be saved without reconfirming an existing automatic assignment. Timing calculations, captured events, stored history and existing review decisions are unchanged.
