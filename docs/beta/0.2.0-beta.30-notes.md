Home now has a Project Explorer. Beneath the day's activity chart, each project is a compact row that expands into its sessions; pick a session to see its agent time, subagents, peak concurrency, a session chart and each agent's recorded details. Focus the main chart on a project when you want its totals, and zoom the chart with a pinch or ⌘-scroll. Agent-reported work has its own section, separate from measured time. Existing captured data is unchanged.
