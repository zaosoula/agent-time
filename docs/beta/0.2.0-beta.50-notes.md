# Agent Time 0.2.0-beta.50

Billing reports prepare history faster by avoiding repeated historical metadata searches and reading older project context in one pass. Existing presence rules, host matching, equal-timestamp context ordering, review decisions and timing/billing calculations are preserved. Reports now show actual completed-day progress, the date being checked, elapsed time and the saving stage. One report runs at a time in the collector to avoid competing workers.

Settings sections load on first visit. Opening Billing no longer also measures storage or discovers website projects. The selected day's activity appears without waiting for optional task declarations or the seven-day review backlog; Review still provides its backlog.

Visited pages now use Vue KeepAlive. Searches and reports continue when you navigate away, and drafts, results, expanded groups, zoom and scroll positions remain available on return. Home and Agent sessions retain separate internal views. Ordinary navigation preserves the shared project/search/session context; explicit project/date changes still update dependent selections. Cached pages release dialogs and focus traps while hidden, then restore their drafts on return. Unchanged weekly and work-evidence results are retained, with stale or discarded requests refreshed when needed.

Page retention is in memory for the current app session, bounded to the eight pages. It does not save page snapshots to localStorage or change the capture database format. Routine refreshes stay limited to the relevant visible page. Existing saved billing reports and policy versions remain unchanged.
