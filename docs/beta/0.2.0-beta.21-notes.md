Agent-reported task context and counters now appear under their project on the day timeline, even when the project is collapsed. A new setting in Settings → Capture, off by default, counts agent task counters as agent time; only time not already measured for that agent and project is added, so nothing is counted twice. Assigning many review items at once no longer stops with “Select up to 500 recorded intervals at a time.” Existing captured data is unchanged.
