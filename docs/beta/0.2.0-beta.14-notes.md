Agent Time uses less memory when opening My Day or querying a busy day through its local MCP server. It sends only the selected day's relevant sessions and issues to the window, and rejects oversized MCP ranges before loading events. In the background, it refreshes the full summary at most once a minute while keeping capture-health checks and the working-agent count responsive. Tracking and saved history are unchanged; totals shown in an unfocused window may be up to one minute behind.
