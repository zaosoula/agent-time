# Agent Time 0.2.0-beta.51

Billing reports now has its own main sidebar page. Select a billable project and dates, generate a report with progress, and export the saved result. Project configuration and versioned policies remain in Settings → Billing. Reports, selected dates and calculations stay available while navigating; the in-memory page cache now holds all nine pages.

Reported work contexts recognize configured billing project IDs, names and aliases regardless of letter case. This fixes false attribution conflicts when a session declares the same project as its captured repository without duplicating the project name in reported-source mappings. Ambiguous identities and conflicting ownership remain errors. Repository basenames are not inferred as aliases.

The correction applies to newly generated reports. Existing saved reports, prices, capture history, timing calculations, sleep/pause exclusions and declared-counter rules remain unchanged. Measured time and billable time can still differ because billing applies its documented exclusions before counting and commercial rounding.
