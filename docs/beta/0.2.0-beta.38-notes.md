Counts Claude Code background shells until they finish. A command run in the background, or moved there after its timeout, now counts as agent time from launch until Claude Code reports it finished, instead of stopping at the five-minute idle limit or when the agent ends its turn. If no finish notice arrives, the shell counts until the agent's turn shows it is gone, or up to the last time it was seen running. Only the background task ID and its status are recorded, never the command. Repair or update hooks after installing so Claude Code sessions report background shells.
