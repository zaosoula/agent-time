Agent Time starts and refreshes faster: past days' review results are reused instead of rebuilt, and the dashboard no longer re-downloads an unchanged day every few seconds. After an update, agent hooks are refreshed automatically instead of asking for a repair, and the repair dialog now explains what changed. The Agent Time menu adds Check for Updates, Pause/Resume Capture and Restart Collector. Agent-reported checkpoints and timers share one row per project and appear on the agent row that reported them. The update banner now appears first, and dismissing the hook dialog is immediate. Existing captured data is unchanged.
